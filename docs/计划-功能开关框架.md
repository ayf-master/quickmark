# 计划：QuickMark 功能开关框架 + 间隔重复样例

> 目标：在保持 QuickMark 基础极简的前提下，用「右上角 ⚙ 功能面板 + 开关」让高级能力按需挂载。间隔重复作为第一个挂上去的样例功能，验证整条丝滑链路。
> 配套架构图与讲解见对话（功能开关架构图：零迁移 / 零刷新 / 分包懒加载 / 内容即数据）。

## 0. 设计原则（丝滑四原则）
1. **零迁移**：可选表随基础迁移一起建好，空着不用；开启功能不碰 DB 结构。
2. **零刷新**：reactive `features` 状态 + `v-if` 条件渲染，UI 原地切换（Vue `<Transition>` 滑入）。
3. **分包懒加载**：功能代码 `import()` 动态分包，默认不进主包，基础包依旧小。
4. **内容即数据**：`[[quiz:问题|答案]]` 从笔记 content 实时正则解析，开关一拨旧笔记立刻变复习卡。

## 1. 已确认的关键决策（均已拍板）
- **D1 开关存哪**：后端 `User.settings` JSON 列（跨设备/重登保持，多用户隔离正确）。
- **D2 框架形态**：清单式注册表（集中声明功能 id/名称/描述/懒加载组件，加功能只改清单）。
- **D3 关闭后数据**：休眠保留（数据留着但隐藏，重开即恢复进度）。
- **D4 后端是否拦截**：服务端也按开关校验 API（防止关了功能仍被直接调接口）。

## 2. 架构总览
前端：
- `src/store/features.js`：reactive 状态 `{ spacedRepetition:false, canvas:false, learningPath:false }`，初始化时从登录返回的 settings 载入，变更时 `PUT /api/settings` 持久化（D1：后端 User.settings）。
- `src/featureManifest.js`：集中声明功能清单（D2 清单式）。每项含 `id / title / desc / loader()`（返回懒加载组件）/`requiresSettings`。
- `src/components/FeaturePanel.vue`：右上角 ⚙ 按钮 → 下拉面板，列出 manifest 里所有功能 + 开关；拨动即改 `features[id]`。
- 功能入口用 `v-if="features.xxx"` 渲染，并包 `<Transition>` 做滑入。

后端：
- `User` 加 `settings` JSON 列（D1：后端 User.settings）存 `{ features: {...} }`；登录响应里带回前端。
- 可选表 `ReviewCard`、`Note.mastery` 随基础迁移建好（空着）。
- 功能 API（`/api/review/*`）按 `req.user.settings.features` 校验（D4：服务端拦截）。

## 3. 数据模型与迁移
- `User.settings`：JSON 列（D1：后端 User.settings，MySQL 5.7+ 支持）。`ALTER TABLE users ADD COLUMN settings JSON ...`
- `ReviewCard` 表：id, userId(FK), noteId(FK), dueDate(DATE), interval(INT), easeFactor(FLOAT), reps(INT), lastGrade(INT), createdAt。
- `Note.mastery`：SMALLINT 0–5，默认 0，驱动知识图谱着色。
- 迁移文件：`prisma/migrations/20260725_add_settings_reviewcard/migration.sql`（JSON 列 + ReviewCard + mastery）。

## 4. 前端实现（关键文件）
- `src/store/features.js`：reactive + 持久化同步（D1 决定 localStorage 是否参与）。
- `src/featureManifest.js`：声明 `spacedRepetition` 等。
- `src/components/FeaturePanel.vue`：面板 UI + toggle + `<Transition>`。
- `src/components/ReviewQueue.vue`：懒加载（`() => import(...)`），复习队列 + 评分翻面。
- `src/components/KnowledgeGraph.vue`：开启后节点按 `mastery` 着色（灰→绿）。
- `[[quiz]]` 解析：复用 `src/utils/wiki-link.js` 思路，正则 `/\[\[quiz:([^\]|]+)\|([^\]]+)\]\]/g` 从 content 实时取，不新增存储。

## 5. 后端实现（关键文件）
- `prisma/settings.js`（新建）：`getSettings(userId)` / `setSettings(userId, settings)` 读写 `User.settings` JSON。
- `server.js`：加 `GET/PUT /api/settings`；`/api/review/*` 路由受 settings 校验（D4）。
- `prisma/dal.js`：加 `listDueCards(userId, today)`、`gradeCard(...)` 调 `sm2.js`、`updateMastery(...)`。
- `prisma/sm2.js`：纯函数 `gradeCard(card, grade)`（实现见 `docs/计划-间隔重复学习系统.md`）。

## 6. 分阶段（一起做，每阶段独立可跑）
- **Phase 0 框架地基**：D1 持久化（后端 User.settings）+ FeaturePanel + featureManifest + 一个「空壳功能」（仅面板开关 + 一处 v-if 文本）验证丝滑四原则。→ 此时基础包未变大、默认无附加功能。
- **Phase 1 挂间隔重复**：ReviewCard 表 + sm2 + 复习队列 UI + `[[quiz]]` 解析 + 评分。→ 开启即见复习队列，旧笔记 `[[quiz]]` 点亮。
- **Phase 2 增强**：知识图谱掌握度着色 + 复习统计（连续天数 / 待复习数）。→ 关闭功能时数据休眠保留（D3：休眠保留）。

## 7. 自测清单
- 默认进入：无 ⚙ 面板外任何附加 UI；主包体积未增。
- 拨开间隔重复：无需刷新，复习入口滑入；旧 `[[quiz]]` 笔记出现在队列。
- 重新登录 / 换浏览器：开关状态保持（D1：后端 User.settings）。
- 关闭间隔重复：复习 UI 消失；已练进度数据仍在（D3：休眠保留），重开恢复。
- 未开启时直接调 `/api/review`：服务端拦截（D4：服务端也按开关校验）。

## 8. 风险与坑
- MySQL 版本：JSON 列需 5.7+；ngram 全文索引需 5.7.6+ / 8（已有迁移）。
- `v-if` 覆盖：关闭功能时所有入口（侧栏、图谱着色、API 调用）都要用 `features.xxx` 守护，避免残留。
- reactive 单例：当前为纯客户端 SPA，无 SSR 风险；若未来上 Nuxt 需改 Pinia SSR 模式（见学习指南 §9）。
- 开关竞态：持久化用 debounce，避免快速连拨发多次请求。

## 9. 实施进度（Phase 0 已完成）
- 后端：`prisma/settings.js`（normalize/merge/get/set + `KNOWN_FEATURES` 白名单）；`server.js` 增加 `GET/PUT /api/settings`（Prisma + pool 双模式，列缺失时优雅降级返回默认）。
- 数据模型：`User.settings Json?`；迁移 `prisma/migrations/20260726_add_user_settings/migration.sql`（`ALTER TABLE users ADD COLUMN settings JSON`）；已 `prisma generate`。
  - ⚠️ 本地 DB 在本环境不可达（ECONNRESET），列未实际执行；需你在本机跑 `npx prisma migrate deploy` 或 `ALTER TABLE users ADD COLUMN settings JSON NULL;` 后开关才会持久化（在此之前仅内存演示）。
- 前端：`src/store/features.js`（reactive + initFeatures/resetFeatures/setFeature + 400ms debounce 持久化）；`src/featureManifest.js`（清单式）；`src/api/index.js` 加 getSettings/updateSettings；`FeaturePanel.vue`（右上角齿轮 + 下拉开关 + Transition 抽屉 + defineAsyncComponent 懒加载）；`FeaturePlaceholder.vue`（空壳，独立分包）。
- 接入：`AppHeader` 右侧渲染 FeaturePanel；`App.vue` 登录后 `initFeatures()`、登出 `resetFeatures()`。
- 校验：`node --check` 后端通过；`npx vite build` 通过，FeaturePlaceholder 被拆成独立 chunk（验证分包懒加载）。
- 待 Phase 1：把 `featuresManifest` 里 `spacedRepetition.loader` 换成真实 `ReviewQueue.vue`，并接 `[[quiz]]` 解析 + 图谱掌握度着色。
