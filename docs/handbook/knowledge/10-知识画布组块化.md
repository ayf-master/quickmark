# 10 · 知识画布（组块化）

> 目标：看懂 `CanvasBoard.vue` 怎么把笔记按分类「分组成块」铺成一张可平移缩放的画布。

## 10.1 为什么组块化

早期画布把所有笔记卡片平铺成一墙，分类混杂、找不到归属。改为**组块化**：按分类把笔记聚成一组，每组一个标题块，组内排卡片。视觉上像「白板上的便签集群」，一眼看懂「这个分类有哪些笔记」。

```js
// 分组：取笔记第一个分类；无分类归入「未归类」
const groups = computed(() => {
  const map = new Map();   // categoryId|'none' -> { name, notes:[] }
  for (const n of store.filteredNotes) {
    const cid = (n.category_ids && n.category_ids[0]) || 'none';
    if (!map.has(cid)) {
      const cat = store.categories.find(c => c.id === cid);
      map.set(cid, { id: cid, name: cat ? cat.name : '未归类', notes: [] });
    }
    map.get(cid).notes.push(n);
  }
  return [...map.values()];
});
```

## 10.2 组位置与自动换行

每个组有坐标 `groupPositions`（响应式，初始由 `layoutGroups` 自动算：从左到右、满了换行）：

```js
const groupPositions = reactive({});  // id -> { x, y }
function layoutGroups() {
  let x = 40, y = 40;
  const COL_W = 320, ROW_H = 280, GAP = 40;
  for (const g of groups.value) {
    groupPositions[g.id] = { x, y };
    x += COL_W + GAP;
    if (x > window.innerWidth - COL_W) { x = 40; y += ROW_H + GAP; }  // 自动换行
  }
}
```

用户拖某个组时只改它的 `groupPositions[id]`，不影响别的组（`onGroupDragStart/Move/End`）。

## 10.3 平移与缩放（指针 + 滚轮 + 双指）

画布根 `canvas-root` 用 `position: fixed; inset:0; z-index:200` 全屏覆盖。交互：

```js
// 平移：在空白处按下拖拽 → 改全局 pan 偏移
function onPointerDown(e) {
  panStart = { x: e.clientX - pan.x, y: e.clientY - pan.y };
  dragging = true;
}
function onPointerMove(e) {
  if (!dragging) return;
  pan.x = e.clientX - panStart.x;
  pan.y = e.clientY - panStart.y;
}
// 缩放：滚轮
function onWheel(e) {
  e.preventDefault();
  const factor = e.deltaY < 0 ? 1.1 : 0.9;       // 上滚放大、下滚缩小
  zoom = Math.min(3, Math.max(0.3, zoom * factor));
}
// 双指缩放（移动端）：两指距离比
function onTouchMove(e) {
  if (e.touches.length === 2) {
    const d = distance(e.touches[0], e.touches[1]);
    zoom = baseZoom * (d / baseDist);
  }
}
```

渲染时把所有组坐标乘 `zoom` 加 `pan`，实现「一处缩放、整体跟随」。

## 10.4 卡片预览：剥离 Markdown/HTML

组里每张卡片显示「纯文本摘要」，所以把正文里的 Markdown 符号、HTML 标签剥掉：

```js
function cardPreview(content) {
  return (content || '')
    .replace(/```[\s\S]*?```/g, '')   // 去代码块
    .replace(/[#>*_`~\-]+/g, '')       // 去 md 标记
    .replace(/<[^>]+>/g, '')           // 去 HTML 标签
    .replace(/\[\[([^\]]+)\]\]/g, '$1') // [[名]] → 名
    .slice(0, 120);
}
```

这样卡片上看到的是干净的笔记摘要，不会把 `# 标题` 之类符号露出来。

## 10.6 本篇知识点小结

- 画布按「首个分类」分组，无分类归入「未归类」，结构清晰。
- 组位置存 `groupPositions`（响应式），拖组只改自己。
- 平移(pan) + 缩放(zoom)，移动端支持双指 pinch。渲染统一 `坐标*zoom+pan`。
- 卡片预览 `cardPreview` 剥 Markdown/HTML，显示纯文本摘要。
- `canvas-root` 全屏 `z-index:200`，覆盖主界面。
