# 11 · 知识图谱（D3 力导向）

> 目标：理解 `KnowledgeGraph.vue` 怎么用 D3 力模拟把笔记关系画成一张可拖拽、能高亮的网络图。

## 11.1 数据从哪来

图谱节点 = 笔记；边 = 笔记正文里的 `[[笔记名]]` wiki 链接（双向：A 链 B，B 也有一条「被 A 链」的反向边）。数据由 `store.graphData` / `store.linkIndex` 预先算好（见 `knowledge/02`）。

```js
const focusId = computed(() => store.graphFocusNoteId);   // 当前正在编辑的笔记
const linkedIds = computed(() => {
  // 与 focus 有直接链接的笔记 id 集合
  const set = new Set();
  for (const e of edges) {
    if (e.source === focusId.value) set.add(e.target);
    if (e.target === focusId.value) set.add(e.source);
  }
  return set;
});
```

## 11.2 颜色与透明度：聚焦高亮

```js
const FOCUS_COLOR = '#f59e0b';   // 当前笔记：橙金
const LINKED_COLOR = '#06b6d4';  // 直接关联：青

function nodeColor(n) {
  if (focusId.value && n.id === focusId.value) return FOCUS_COLOR;
  if (linkedIds.value.has(n.id)) return LINKED_COLOR;
  return masteryColor(n);   // 其余按掌握度 hsl(0→120°) 着色
}
function nodeOpacity(n) {
  if (!focusId.value) return 1;                 // 没聚焦 → 全亮
  return (n.id === focusId.value || linkedIds.value.has(n.id)) ? 1 : 0.25;
}
function edgeColor(e) {
  return (focusId.value && (e.source === focusId.value || e.target === focusId.value))
    ? LINKED_COLOR : '#94a3b8';
}
```

**效果**：打开某篇笔记时，图谱自动聚焦它（橙金）并高亮邻居（青），其余节点淡出——一眼看出「这篇笔记连着谁」。

掌握度着色 `masteryColor`：

```js
function masteryColor(n) {
  const m = n.mastery ?? 0;        // 0-5
  const h = (m / 5) * 120;         // 0→红(0°), 5→绿(120°)
  return `hsl(${h}, 70%, 55%)`;
}
```

## 11.3 力模拟：让图「自己散开」

D3 `forceSimulation` 用物理模型自动布局，不用手摆坐标：

```js
import { forceSimulation, forceLink, forceManyBody, forceCenter, forceCollide } from 'd3-force';

function initSimulation() {
  // 初始圆形布局，避免全部叠在中心
  nodes.forEach((n, i) => {
    const a = (i / nodes.length) * 2 * Math.PI;
    n.x = Math.cos(a) * 200 + width / 2;
    n.y = Math.sin(a) * 200 + height / 2;
  });

  sim = forceSimulation(nodes)
    .force('link', forceLink(edges).id(d => d.id).distance(90))
    .force('charge', forceManyBody().strength(-260))   // 节点互相排斥，散开
    .force('center', forceCenter(width / 2, height / 2))
    .force('collide', forceCollide(28))                 // 防重叠
    .on('tick', draw);                                  // 每帧重绘

  sim.tick(30);   // 预跑 30 帧，打开时图已基本稳定，不晃
}
```

- `forceManyBody(-)`：负强度 = 斥力，节点互相推开。
- `forceLink`：边像弹簧，把相连节点拉到一起。斥力+引力平衡 → 自然聚簇。
- `forceCollide`：硬碰撞半径，避免卡片叠在一起。
- `sim.tick(30)` 预热：打开浮层时图已经接近稳态，体验顺滑。

## 11.4 绘制：SVG + 箭头 + 曲线边

```js
function draw() {
  // 用 d3-selection 更新 SVG 元素
  const link = svg.selectAll('line').data(edges, d => d.id);
  link.join('line')
    .attr('x1', d => d.source.x).attr('y1', d => d.source.y)
    .attr('x2', d => d.target.x).attr('y2', d => d.target.y)
    .attr('stroke', edgeColor).attr('stroke-opacity', edgeOpacity);

  const node = svg.selectAll('circle').data(nodes, d => d.id);
  node.join('circle')
    .attr('r', 9).attr('cx', d => d.x).attr('cy', d => d.y)
    .attr('fill', nodeColor).attr('fill-opacity', nodeOpacity)
    .call(drag(sim));   // 可拖拽
}
```

双向链接（A→B 且 B→A）画成**曲线**避免重叠；箭头用 `<marker>` 定义方向。

## 11.5 交互：拖拽 + 缩放 + 聚焦

```js
import { drag } from 'd3-drag';
import { zoom } from 'd3-zoom';

// 拖节点：固定它的位置 (fx/fy)，松手释放
function drag(sim) {
  return drag()
    .on('start', (e, d) => { if (!e.active) sim.alphaTarget(0.3).restart(); d.fx = d.x; d.fy = d.y; })
    .on('drag',  (e, d) => { d.fx = e.x; d.fy = e.y; })
    .on('end',   (e, d) => { if (!e.active) sim.alphaTarget(0); d.fx = null; d.fy = null; });
}

// 聚焦当前笔记：把它钉在中心
watch(focusId, (id) => {
  const n = nodes.find(x => x.id === id);
  if (n) { n.fx = width / 2; n.fy = height / 2; sim.alpha(0.3).restart(); }
});

// 缩放/平移
svg.call(zoom().scaleExtent([0.2, 4]).on('zoom', (e) => rootG.attr('transform', e.transform)));
```

`fx/fy` 是 D3 的「固定坐标」：设了就钉住，设 `null` 释放回物理模拟——实现「聚焦节点停在中心」。

## 11.6 浮层 Esc 优先级

图谱浮层 `@keydown.escape.stop` + `overlayRef.focus()`：在图谱里按 Esc 只关图谱，不穿透到编辑器/预览的 Esc 处理。和标注层同理（见 `knowledge/09`）。

## 11.7 本篇知识点小结

- 节点=笔记，边=wiki 链接（含反向），数据由 store 预计算。
- 聚焦当前笔记橙金、邻居青、其余淡出，掌握度按 hsl 着色。
- 力模拟：`forceManyBody`(斥) + `forceLink`(引) + `forceCollide`(防叠)，`tick(30)` 预热。
- 可拖拽（`fx/fy` 钉位）、可缩放（d3-zoom）、聚焦节点钉中心。
- `@keydown.escape.stop` 控制浮层关闭优先级。
