# 07 · 笔记编辑器与自动保存

> 目标：搞懂编辑器怎么渲染 Markdown、怎么做「无感自动保存」、以及「切笔记丢修改」这个经典坑是怎么修的。

## 7.1 编辑器两种模式

`NoteEditor.vue` 支持纯文本(`plain`)与 Markdown(`markdown`)两种模式，存于 `store.editMode`：

```html
<div v-if="store.editMode === 'markdown'">
  <textarea ref="contentInput" @input="onEditorInput" v-model="..."></textarea>
  <!-- markdown-it 实时预览 -->
</div>
<div v-else-if="store.editMode === 'plain'">
  <textarea ref="plainInput"></textarea>
</div>
```

模式切换 `switchMode(target)`：切到 `plain` 时把 `store.editContent` 塞进 `plainInput.value`，保证内容不丢。组件用一个 `isAlive` 标志防止卸载后回调副作用（见 7.6）。

## 7.2 Markdown 渲染 + 自研插件

预览用 `markdown-it`，并挂两个自研插件：
- `wikiPlugin`（`[[笔记名]]` → 可点击的内部链接）
- `renderAnnotations`（`<!-- qm-annot -->` 类标注渲染）

```js
import markdownit from 'markdown-it';
import wikiPlugin from '@/utils/markdown-it-wiki';
import { renderAnnotations } from '@/utils/markdown-it-annotations';

const md = markdownit({ html: false, linkify: true, breaks: true })
  .use(wikiPlugin)
  .use(renderAnnotations);
```

`html:false` 关闭原始 HTML 渲染，防 XSS（用户内容里的 `<script>` 会被当文本）。

## 7.3 mdInsert 光标 bug（已修）

早期多图粘贴会出现 `![a![b![c](...)` 嵌套。根因：插入后光标停在 `prefix` 之后、`suffix` 之前，下一次插入嵌进 suffix 前面。修复：光标停在**完整新文本末尾**：

```js
function mdInsert(prefix, suffix, placeholder) {
  const ta = contentInput.value;
  const start = ta.selectionStart, end = ta.selectionEnd;
  const selected = ta.value.slice(start, end) || placeholder || '';
  const newText = prefix + selected + suffix;
  const before = ta.value.slice(0, start), after = ta.value.slice(end);
  ta.value = before + newText + after;
  const cursor = start + newText.length;     // ✅ 停在完整 newText 末尾
  ta.setSelectionRange(cursor, cursor);
  store.scheduleAutoSave();
}
```

## 7.4 自动保存：1s 防抖

`store.scheduleAutoSave()` 是全局防抖入口，`watch(editTitle/editContent)` 触发它：

```js
// src/store/index.js
let autoSaveTimer = null;
scheduleAutoSave() {
  clearTimeout(autoSaveTimer);
  const noteId = store.editingNote ? store.editingNote.id : null;  // 快照
  autoSaveTimer = setTimeout(() => {
    autoSaveTimer = null;
    if (noteId && store.editingNote && store.editingNote.id === noteId) {
      store.saveCurrentNote().then(() => store.loadCategories());
    }
  }, 1000);
}
```

**为什么在 setTimeout 里再核对 `noteId`？** 因为 1 秒后用户可能已切到别的笔记，`store.editingNote.id` 变了。用闭包快照的 `noteId` 比对，确保「保存的是当时正在编辑的那篇」，不会把 B 的内容写进 A。

## 7.5 切笔记丢修改：经典坑（已修）

**坑**：点列表项 B，`openNote(B)` 直接把 `store.editContent` 覆盖成 B 的内容；而上一秒的 `scheduleAutoSave` 1s 定时器还没跑，闭包里 `editingNote` 已是 B → A 的最后编辑永远没保存。用户感知「保存失效」。

**修法**：`openNote` 在切换前，fire-and-forget 先把旧笔记存盘：

```js
openNote(note, options = {}) {
  const prevId = store.editingNote ? store.editingNote.id : null;
  if (prevId && prevId !== note.id) {
    store._persistCurrentEdit().catch(err => console.warn('切换前保存失败:', err));
    store.cancelAutoSave();          // 取消旧定时器，避免和当前笔记冲突
  }
  // ... 之后才覆盖 editingNote / editContent
}

async _persistCurrentEdit() {
  if (!store.editingNote?.id) return;
  const noteId = store.editingNote.id;            // ✅ await 前快照
  const snapTitle = store.editTitle || '无标题';
  const snapCategoryIds = [...store.editCategoryIds];
  let content = store.editContent || '';
  // 把 editLinks 序列化进正文末尾的 HTML 注释标记
  if (store.editLinks.length) {
    content = content.replace(/<!--\s*qm-links:[\s\S]*?-->\s*/g, '').trim()
      + '\n<!-- qm-links:' + JSON.stringify(store.editLinks) + ' -->';
  }
  await API.updateNote(noteId, { title: snapTitle, content, category_ids: snapCategoryIds });
  // 同步本地 store.notes[i]，防 loadNotes 覆盖丢失
}
```

**要点**：链接(`[[笔记名]]` 的标注数据)存在正文末尾的 `<!-- qm-links:[...] -->` 注释里——既随笔记走、又不污染 Markdown 渲染（注释不显示）。`openNote` 读取时反向解析这个标记还原成 `store.editLinks`（`knowledge/11` 图谱用）。

## 7.6 撤销/重做 + 组件存活保护

编辑器自带 undo/redo（`historyUndo`/`historyRedo` 栈），带光标位置恢复，并有个「合并窗口」`historyMergeMs`：快速连续打字合并成一条历史，避免一步一撤销。

```js
const isAlive = true;   // 模块级标志
onBeforeUnmount(() => {
  isAlive = false;       // 阻止卸载后的 setTimeout/事件回调改状态
  stopWatchNote(); stopWatchMode();
  document.removeEventListener('keydown', onKeydown);
});
```

全局快捷键 `onKeydown`（Ctrl/Cmd+Alt+M 切 MD、+P 切纯文本、Alt+← 回退、Alt+→ 前进）绑定在 `document`，卸载时务必移除，否则内存泄漏 + 串台。

## 7.7 本篇知识点小结

- 编辑器双模式：markdown-it 预览，`html:false` 防 XSS。
- mdInsert 光标停在完整文本末尾，修好多图嵌套。
- 自动保存 = `watch → scheduleAutoSave`（1s 防抖），闭包快照 noteId 防串台。
- 切笔记前 fire-and-forget `_persistCurrentEdit` + `cancelAutoSave`，修「丢修改」。
- 链接数据存正文 `<!-- qm-links -->` 注释，随笔记走且不渲染。
- `isAlive` + `onBeforeUnmount` 清监听，防卸载后副作用。
