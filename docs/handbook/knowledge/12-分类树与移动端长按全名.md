# 12 · 分类树与移动端长按全名

> 目标：理解递归分类树组件，以及一个真实修过的移动端 bug（长按显示全名），它暴露了「截断检测」和「浮层定位」两个经典前端坑。

## 12.1 递归树组件

`CategoryTreeNode.vue` 渲染一个节点，若有 `children` 就递归渲染自己：

```html
<template>
  <div class="cat-node">
    <div class="cat-row" @click="select(node)">
      <span ref="nameSpanRef" class="truncate" :title="node.name" v-text="node.name"></span>
      <span class="cat-count">{{ node.count }}</span>
    </div>
    <div v-if="node.children?.length" class="cat-children">
      <CategoryTreeNode v-for="c in node.children" :key="c.id" :node="c" />
    </div>
  </div>
</template>
```

树结构由 `store.categoryTree` 算好（见 `knowledge/02`），组件只负责渲染。点击选中 → `store.selectedCategoryId = node.id`，列表跟着过滤。

## 12.2 后端防循环引用

分类支持多级，但「A 的父是 B、B 的父又是 A」会成环，递归爆炸。后端 `PUT /api/categories/:id` 在改 `parentId` 前用 BFS 检查目标父是否是自己的后代：

```js
// server.js（示意）
app.put('/api/categories/:id', async (req, res) => {
  const { parentId } = req.body;
  if (parentId) {
    const descendants = getDescendantIds(Number(req.params.id), allCats); // 见 knowledge/04
    if (descendants.includes(Number(parentId))) {
      return res.status(400).json({ error: '不能把分类移到自己的子分类下' });
    }
  }
  // ... 更新
});
```

## 12.3 移动端长按显示全名（本次修复的 3 个 bug）

**场景**：手机侧栏窄，长分类名被 CSS 截断成 `计算机科学技…`。用户长按名称，应弹出一个**不被截断的全名提示框**。原实现有三个 bug：

### Bug 1：提示框自己又被截断（反模式）
```css
/* 错误：提示框也用了同一套截断样式 */
.cat-name-tip { max-width: 80vw; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
```
结果长名在提示框里还是 `…`，等于没修。**修法**：提示框用 `white-space:normal; overflow-wrap:anywhere; max-width:86vw`，允许换行显示完整名。

### Bug 2：不管名字超没超宽都弹
原代码每次长按都弹提示，短名也弹，多余。修法：用 `scrollWidth > clientWidth` 检测「是否真的被截断」，只有截断才弹：

```js
const span = nameSpanRef.value;
const truncated = !span || span.scrollWidth > span.clientWidth + 1;
if (truncated) {            // ✅ 只在被截断时弹
  nameTip.x = touchDrag.startX;
  nameTip.y = touchDrag.startY;
  nameTip.below = touchDrag.startY < 80;   // 靠近顶部就显示在下方
  nameTip.visible = true;
}
```

`scrollWidth`（内容真实宽）> `clientWidth`（可见宽）是「文本溢出被截断」的标准判定法，比猜测字符数可靠。

### Bug 3：顶部分类的提示框跑到屏幕外
原 `transform: translate(-50%, -130%)` 把提示框往上挪，但最顶上的分类名本身就在屏幕顶部，上挪后整框飞出可视区。修法：加 `below` 标志，靠近顶部时改为显示在下方：

```css
.cat-name-tip { transform: translate(-50%, calc(-100% - 8px)); }   /* 默认上方 */
.cat-name-tip.tip-below { transform: translate(-50%, 8px); }       /* 顶部时下方 */
```

### 长按触发逻辑
```js
let longPressTimer = null;
function onTouchStart(e) {
  touchDrag.startX = e.touches[0].clientX;
  touchDrag.startY = e.touches[0].clientY;
  longPressTimer = setTimeout(() => showTip(), 500);  // 按住 500ms 才弹
}
function onTouchEnd() { clearTimeout(longPressTimer); nameTip.visible = false; }
```

`touchstart` 起 500ms 定时器，`touchend`/`touchmove` 清除——移动了一点就当滚动、不弹，避免和列表滚动冲突。

## 12.4 拖拽重排分类

侧栏分类可拖拽排序，松手 `PATCH /api/categories/reorder` 重写 `position`，与笔记排序同理（见 `knowledge/08`）。

## 12.5 本篇知识点小结

- 分类树 = 递归组件 + `store.categoryTree` 预计算结构。
- 后端 BFS 防循环引用，杜绝「父是子」死循环。
- 截断检测用 `scrollWidth > clientWidth`，比数字符准。
- 长提示框要允许换行（`white-space:normal`），否则二次截断。
- 浮层定位靠 `below` 标志避开屏幕顶/底边缘。
- 长按用 500ms 定时器 + `touchmove` 清除，区分「长按」与「滚动」。
