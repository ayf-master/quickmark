## 1. 项目一句话介绍

**QuickMark** 是一个多用户笔记应用（类似轻量版 Notion / 语雀），核心亮点是：

- 📝 笔记管理：多级分类、Markdown 编辑、图片上传、全文搜索（中文 ngram）
- 🧠 间隔重复复习：基于 SM-2 算法（Anki 同款）提醒你复习到期笔记
- 📊 计划甘特表：给笔记设起止日期，用甘特图直观展示时间规划与进度
- 🎨 知识画布：无限缩放的白板，笔记是可拖拽的卡片（D3.js）
- 🔐 完整的用户系统：注册/登录、JWT + Refresh Token、CSRF 防护、找回密码（邮箱验证码）

**技术栈一句话**：Vue 3 前端 + Express 后端 + Prisma ORM + MySQL + Redis，Docker 容器化部署，PM2 进程守护。

## 5. 三个必须先懂的核心概念（跨章节的全局观）

### 5.1 前后端如何通信

```
浏览器 (Vue)  ──fetch /api/notes──▶  服务器 (Express)
   ◀────── JSON 数据 ──────────────
```

- 前端不直接碰数据库，所有数据都通过 **HTTP API**（JSON 格式）获取
- 开发时前端跑在 `localhost:5173`（Vite），后端在 `localhost:3000`，Vite 代理转发（见 vite.config.js）
- 生产时前端构建成静态文件（dist/），由后端 Express 直接托管

### 5.2 登录态如何保持（一句话版）

登录成功 → 服务器发 3 个 Cookie（access token + refresh token + CSRF token）
→ 浏览器每次请求自动带上 → 服务器校验 token 识别"你是谁"
→ access 过期（1h）自动用 refresh（30d）换新的。

详细原理见 `06-认证与安全.md`。

### 5.3 数据流全景（以"创建一篇笔记"为例）

```
1. 用户在 NoteEditor 输入标题内容，点保存
2. 前端 store.saveCurrentNote() 调用 API.updateNote(id, data)
3. api/index.js 封装 fetch：POST /api/notes/:id + CSRF 头
4. Express: 全局鉴权中间件验 token → 路由处理函数
5. routes 调 prisma/dal.js 的 updateNote()
6. dal 用 Prisma Client 执行 SQL UPDATE notes SET ...
7. 返回 JSON → 前端更新本地状态 → 界面刷新
```

走一遍这个流程，你就理解了全栈项目的骨架。后面所有文档都是往这个骨架上填肉。

## 6. 学习方法建议

1. **不要背代码**，背"为什么"：为什么用 JWT 而不是 session？为什么甘特图用 CSS 定位？
2. **边读边改**：读文档时随时在项目里改一个小功能验证理解
3. **画图记忆**：架构图、流程图自己画一遍印象最深
4. **写博客**：把每个核心知识点写成文章，面试前翻自己的文章最有效
5. **最终目标**：能不看文档，向别人完整讲 30 分钟这个项目
